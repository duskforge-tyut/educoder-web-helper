# 头歌本地实训助手

基于 [hecongnan/educoder-cli](https://github.com/hecongnan/educoder-cli) 的本地网页界面，通过浏览器选择课堂、实训、关卡与本地代码文件，提交至头歌评测。

## 功能

- 账号密码登录，读取课堂、实训及本章关卡。
- 上一关／下一关、题目正文、目标文件、代码预览和评测结果。
- 选择本地源文件或填写完整路径，提交选中关卡。
- 刷新页面恢复账号、课堂、实训与关卡位置。
- 密码不保存，登录状态仅在后台内存中；服务重启需重新登录。
- 仅监听 `127.0.0.1:8765`，不添加开机启动项。

## 安装（Windows）

需要已有 Python 3.10+，并可通过 `python` 命令调用。将项目放在 D 盘，例如 `D:\_APP\educoder-web-helper`。

1. 双击 `install.cmd`，在项目目录创建独立环境、下载依赖，缓存和临时文件也保存在项目目录。
2. 在本机设置 `EDUCODER_AK`、`EDUCODER_SK` 环境变量，值需来自你有权使用的配置。本仓库不包含签名密钥，也不会自动下载这些值。未配置时连接平台会提示错误。
3. 双击 `start.cmd`，打开 <http://127.0.0.1:8765/>。
4. 登录后选择课堂、实训和关卡；选择完整源代码文件，核对后提交。

关闭浏览器不会停止后台程序。本项目没有安装系统服务或开机启动项。

## 限制

- 单人本机使用，一次后台仅支持一个共享账号状态；不要开放到公网。
- 仅处理代码实训，不支持选择题、试卷，不附带答案或自动解题能力。
- 提交会覆盖选中关卡的目标文件，代码需保留题目要求的完整结构。
- 部分账号可能被平台拒绝接口密码登录；部分关卡需在官网先开启或评测。
- 平台接口变化、登录过期等会影响使用；分数与完成状态以平台为准。
- 后台仍是 Python HTTPX。Chrome 格式 User-Agent 不代表真实浏览器通信，不保证不会被识别。

## 数据

提交日志在项目内 `logs/file-submissions.md`，记录日期、来源文件和目标关卡，不记录密码或答案正文。密码、Cookie、签名密钥、本地答案、日志、环境和缓存不纳入仓库。刷新后需重新选择答案文件。
